# Playground

Scratch space for experiments. Your instructor creates demo files here to
answer your questions with runnable code.

Demos are grouped by lesson, one folder per module, named exactly like the
module directory (e.g. `02-values-variables/`). A folder only exists once a
lesson has a demo. Run any file with
`uv run python playground/<NN-module>/<file>.py`.

| Folder | Demos |
|---|---|
| [01-setup-tooling/](01-setup-tooling/) | `__name__` and imports (`whoami.py`, `importer.py`) |
| [02-values-variables/](02-values-variables/) | labels vs boxes, numbers, strings, `split`/`strip`/`join`, comprehensions |
